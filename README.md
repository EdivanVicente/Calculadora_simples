Calculadora Simples
Calculadora web desenvolvida com HTML, CSS e JavaScript puro (sem frameworks ou bibliotecas externas).

Demo
https://edivan.vicente.github.io/Calculadora_simples/

Funcionalidades
Operações básicas: soma, subtração, multiplicação e divisão
Limpar (C) e apagar último caractere (<)
Histórico da última operação
Suporte a teclado físico
Tratamento de erros de expressão inválida
Layout responsivo (desktop, tablet e mobile)
Tecnologias
HTML5
CSS3 (Grid, Container Queries, clamp())
JavaScript (ES6+)
Estrutura
Calculadora_simples/ ├── index.html ├── css/style.css ├── js/script.js └── img/favicon.png
## Como rodar
git clone https://github.com/EdivanVicente/Calculadora_simples.git
Abra o `index.html` no navegador ou utilize a extensão Live Server no VS Code. ## Autor Edivan Vicente
